# Frontend

Next.js frontend for Choosy.

## Setup

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 13
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

- Runs on `http://localhost:3000`
- Auto-reloads on file changes

## Environment

Create `.env.local` with:
```
NEXT_PUBLIC_API_URL=http://localhost:8000
```
