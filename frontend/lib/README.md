# Frontend Utilities

This folder contains frontend utilities, hooks, and helpers for Choosy.

- `api.ts`: API helpers.
- `auth.tsx`: Auth logic.
- `darkMode.tsx`: Dark mode hook.
- `locationDetection.ts`: Geolocation helpers.
- `security.ts`: Security helpers.
- `utils.ts`: General utilities.
- `validation.ts`: Validation logic.

## Usage

Import utilities from here to keep frontend code DRY and maintainable.
